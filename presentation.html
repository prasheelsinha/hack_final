Execution Modes

🖥️ Local Mode

  • Direct access to system resources
  • Real-time screen interaction and monitoring
  • Perfect for development and quick testing
  • Example: python main.py

🐳 Docker Mode

  • Isolated containerized environment
  • Guaranteed reproducibility across systems
  • Multiple containers for parallel testing
  • Ideal for CI/CD pipelines and regression testing
  • Example: docker-compose up -d agent-test

Quick Start Guide

Setup (Local)

# Create virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the web UI
streamlit run streamlit_app.py

Docker Setup

# Build and run container
docker-compose build
docker-compose up agent
